# Aeros

Projet Unreal Engine 5.8 hôte du plugin **Aeros Weather** : météo et catastrophes naturelles réalistes et optimisées.

* Plugin : [`Aeros/Plugins/AerosWeather`](Aeros/Plugins/AerosWeather/README.md) (documentation, démo, touches)
* Cahier des charges / roadmap : [`Docs/Aeros/Cahier des charges - Roadmap.md`](Docs/Aeros/Cahier%20des%20charges%20-%20Roadmap.md)

Démo rapide : ouvrir `Aeros/Aeros.uproject`, puis dans n'importe quel niveau *World Settings → GameMode Override = AerosDemoGameMode* → Play.
